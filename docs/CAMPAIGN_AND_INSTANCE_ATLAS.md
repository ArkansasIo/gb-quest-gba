# Aelmoor Campaign, Quests & Instance Atlas

## Original-content boundary

This is an original campaign for a fantasy ARPG using broad fifth-edition tabletop concepts: ability checks, exploration, tactical encounters, roleplay choices, creature roles, rests, hazards, and tiered rewards. It does not reproduce published D&D adventure text, named settings, proprietary maps, stat blocks, or boxed text. All names, stories, quest chains, encounter maps, and game data here are original to this project.

## Campaign scope

- 12 acts across Aelmoor's nine realms.
- 5 main quests and 3 side quests per act: 60 main quests and 36 side quests.
- Stable IDs, zone references, level bands, objective chains, rewards, and map references.
- Side quests can affect settlement services, companion dialogue, faction reputation, or later reinforcements.
- Each act ends with a named boss and arena map reference.

## Fifth-edition-inspired encounter design

Use original game data rather than importing published stat blocks. Enemy roles can include brute, skirmisher, artillery, controller, support, and solo boss. Encounters should support telegraphed actions, cover, elevation, hazards, ability checks, saving throws, conditions, rests, and non-combat solutions. Balance all game formulas against this project's level 1-720 progression.

## Implementation boundary

This commit adds campaign and instance design data, not completed playable quest logic or finished dungeon tile art. Runtime work remains: quest journal and objective persistence; branching dialogue and choice flags; encounter spawners; map renderer; instance entry/exit; party scaling; boss phases; reward validation; tower floor generation; save migration; and automated tests. Online rewards must be validated server-side to prevent duplication.
